# Network Services

## DHCP

DHCP was configured to automatically assign IP addressing information to clients.

The DHCP configuration provides clients with the required network parameters.

## SSH

SSH was configured for secure remote access to the router.

The configuration was tested from a client PC.

## DNS

A DNS server was configured to resolve the web server domain name to its IP address.

## HTTP

An HTTP server was configured to host a web page.

The service was tested by accessing the website through its domain name.

## Verification

The following were verified:

- DHCP address assignment
- SSH connectivity
- DNS resolution
- HTTP accessibility
